# `@flyingrobots/geordi-profunctor-page`

This package lowers one aligned `profunctor-page/0` artifact family into
bounded structural Geordi evidence. It validates exact input relationships and
emits deterministic `geordi-ir/1`, target-map, receipt, and SVG artifacts.

The package does not own page content or publication semantics, render general
text, activate native links, or inherit semantic HTML claims.

See
[Lower a Profunctor Page into structural Geordi evidence](../../docs/profunctor-page-target.md)
for supported inputs, outputs, diagnostics, runnable commands, and claim
boundaries.
